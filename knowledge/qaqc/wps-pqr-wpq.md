# WPS, PQR and WPQ

Welding qualification separates two questions: *is the procedure capable
of producing sound welds with the required properties?* and *is this
welder capable of following it?*

## WPS — Welding Procedure Specification

The **WPS** is the written instruction used on the shop floor or at site.
It specifies the ranges of variables a welder must work within, such as:
welding process, base material groups and thickness range, filler metal,
joint design, position, preheat and interpass temperature, post-weld heat
treatment, shielding gas, and electrical parameters (current, voltage,
travel speed / heat input).

## PQR — Procedure Qualification Record

The **PQR** is the **record** of the actual test weld made to qualify a
WPS: the actual values of variables used, and the results of the required
tests (e.g. tensile, bend, impact/toughness, hardness, NDT as required).
It is a factual, historical record and is not revised to change what was
done.

## The difference between WPS and PQR

| | WPS | PQR |
|---|---|---|
| Purpose | Instruction for production welding | Evidence that the procedure works |
| Content | Allowed **ranges** of variables | **Actual** values used in the test weld + test results |
| Used by | Welders, supervisors, inspectors | Reviewers/approvers of the WPS |
| Changes | Can be revised within qualified limits | Not changed; a new PQR is needed for new essential variables |

A WPS is supported by one or more PQRs. If an **essential variable**
changes beyond the qualified range, a new or additional PQR is required.

## WPQ — Welder Performance Qualification

The **WPQ** (also called welder qualification test record) shows that an
individual welder has made an acceptable test weld following a WPS. It
defines the range the welder is qualified for (process, position,
thickness, diameter, etc.) and must be kept current per the applicable
code's continuity rules.

## Codes

Welding qualification rules come from the governing code — for example,
ASME Section IX is widely used for pressure equipment and piping, and the
ISO 15614 / ISO 9606 series is common in other regions. Which variables
are essential, and which tests are required, depend on the code and the
project specification, so always check those documents.

## Inspector's checklist

- Is the WPS approved and supported by a valid PQR?
- Do production parameters fall within the WPS ranges?
- Is each welder qualified (valid WPQ) for the process, position and thickness in use?
